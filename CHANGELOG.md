# Changelog

## 0.2.0

- Commit message generation from staged changes, falling back to unstaged changes and untracked files
- Sparkle button in the Source Control title bar plus a command palette entry
- `commitModel` and `maxCommitDiffChars` settings

## 0.1.0

Initial release.

- Inline ghost text completions from the GLM Coding Plan endpoint
- API key in secret storage with an environment variable fallback
- Output sanitizer for fences, echoed code, and bracket duplication
- Status bar state, manual trigger command, and per-language exclusions
